# RELO — Fashion Affiliate Storefront

A responsive, editable fashion-discovery storefront built with plain HTML, CSS and JavaScript.

## Important: Google Sites hosting limitation

Google Sites does **not** provide normal web hosting for a complete HTML/CSS/JavaScript project. You cannot upload this folder and make Google Sites serve `index.html` as the site. Google Sites can embed an externally hosted page or a limited HTML embed inside an iframe.

This project is designed to work as:
1. A complete standalone storefront, hosted on a static host; and
2. An embedded storefront inside a Google Sites page.

If you require Google Sites to be the only host, use Google Sites' native pages and product content instead. A full custom app with editable product data, dynamic filtering and custom JavaScript is not reliably deployable as a native Google Sites site.

## Files

- `index.html` — page structure, navigation, SEO metadata and disclosure.
- `styles.css` — responsive pastel styling.
- `app.js` — search, category filter, sorting, rendering and click-count logging.
- `products.js` — editable product catalogue.
- `README.md` — setup and compliance notes.

## 1. Edit your products

Open `products.js`. Each product looks like this:

```js
{
  id: "unique-product-id",
  name: "Product name",
  category: "Clothing", // Clothing, Bags, Jewellery, Shoes, Accessories
  price: "799",         // use "" if you don't want to show a price
  currency: "INR",
  description: "Short, factual description.",
  platform: "Meesho",   // retailer/platform label
  imageUrl: "https://example.com/your-authorized-product-image.jpg",
  affiliateUrl: "PASTE_THE_EXACT_AFFILIATE_URL_HERE",
  tags: ["casual", "minimal"],
  featured: true,
  active: true
}
```

Rules:
- Keep each `id` unique.
- `active: false` hides a product without deleting it.
- Use `featured: true` to move a product toward the top in Featured sorting.
- Use only images you are allowed to use (affiliate-program product feeds, retailer-approved assets, or your own images).
- Replace demo records and all placeholder content before publishing.
- The demo products have no affiliate links or prices; their buttons are intentionally disabled until you add a valid URL.

## 2. Preserve affiliate tracking

Paste the affiliate URL exactly as generated by the affiliate platform, including every query parameter and tracking token. The storefront assigns that exact string to the outbound link. It does not shorten, rewrite, wrap, strip parameters, or redirect the link.

Before publishing:
- Test each affiliate URL from the live embedded page.
- Confirm that your affiliate program permits Pinterest traffic and intermediary landing pages.
- Follow the platform's rules for product images, price display, disclosures, and link placement.
- Do not use a generic share/invite URL if the program requires a product-specific tracking link.
- Do not claim that a click is commission-eligible until you have verified it in the affiliate dashboard.

## 3. Click tracking

The app stores a basic per-product outbound-click count in the visitor's browser `localStorage` under `relo_affiliate_clicks`. This is a local diagnostic only:
- It is not a central analytics dashboard.
- It does not record orders, sales, commissions, or unique visitors.
- It can be cleared by the visitor and is not shared between devices.
- Affiliate network reporting is the source of truth for conversions and commission.

For centralized analytics, add an analytics provider only after reviewing its privacy requirements and configuring its measurement ID. Do not put private affiliate account credentials in client-side code.

## 4. Google Sites embedding

Recommended route:
1. Publish this project to a static host that serves HTML/CSS/JS (for example, a free static hosting service).
2. Copy the published HTTPS URL.
3. In Google Sites, open the page where the shop should appear.
4. Choose **Insert → Embed → By URL**.
5. Paste the published storefront URL and insert it.
6. Resize the embed frame to give the storefront enough height and width.
7. Publish the Google Site and test on desktop and mobile.

Google Sites' embed frame can show the storefront, but the external storefront remains hosted by the static host. If the host blocks iframe embedding, use the host's allowed embed settings or link to the storefront from Google Sites instead.

## 5. SEO notes

The standalone page includes a title, description, Open Graph tags, responsive viewport, semantic headings and a basic WebSite JSON-LD block. When embedded, search engines may treat the iframe content separately from the Google Sites page. Add a relevant title and description to the Google Sites page itself, and link to important category pages where possible. Do not expect metadata inside an iframe to automatically become metadata for the parent Google Sites page.

## 6. Disclosure

The page includes a general affiliate disclosure. Confirm it meets the disclosure rules of every affiliate program and the laws/regulations applicable to your audience. Put a clear disclosure on Pinterest Pins as well as near affiliate links where required. Do not hide disclosure in a footer only.

## 7. Contact and brand details

Replace `hello@example.com` in `index.html` with an email address you control. Brand name is **RELO** (one E after R, not REELO).

## 8. Run locally

Open `index.html` in a modern browser. For best results, use a simple local web server or a static host because some browser features behave differently when opening files directly.
